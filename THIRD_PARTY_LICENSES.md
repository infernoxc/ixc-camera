# Third-party components

IXC Camera currently bundles **no third-party source code or binaries**.

It links only against Windows system components that ship with Windows and the Windows SDK import libraries (kernel32, user32, gdi32, shell32, ole32). The C++ runtime is linked statically from the Microsoft Visual C++ toolset under the Visual Studio license terms, which allow redistribution of compiled applications.
