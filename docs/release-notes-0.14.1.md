# IXC Camera 0.14.1

Download **IXC-Camera-Setup-x64.exe** below and run it. Close apps that use the camera first. Your settings are kept.

## Fixed
- **Settings were blank in 0.14.0.** Camera, Effects, Background, Profiles, Settings and Updates showed empty cards with no controls. All sliders, switches and lists are back in every section.

Everything else is as in 0.14.0 (new layout, live sync with other apps, smoother blur edges, in-app updates).
